SMTP CREDENTIALS

SMTP setup tips

Gmail: host smtp.gmail.com, port 587, STARTTLS on. You must use an app password (not your account password) — generate one at myaccount.google.com/apppasswords after enabling 2FA. The "From" address must match the username.

SendGrid: host smtp.sendgrid.net, port 587, username literally apikey, password is your API key.

Mailgun: host smtp.mailgun.org, port 587, username from your domain's SMTP credentials in the dashboard.

SMTP2GO: host mail.smtp2go.com, port 2525 or 587, credentials from the dashboard.
