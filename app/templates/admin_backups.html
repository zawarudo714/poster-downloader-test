HOW THIS WORKS

Daily auto-backups are created at 00:00:05 server time via SQLite's online backup API (no service interruption). They live in the backups/ folder under the project root.

If the server is offline at midnight, a catch-up backup runs at startup.

Auto-backups are pruned to the last 14 days. Manual snapshots are never auto-pruned.

Restore: the live poster.db is replaced. The DB connection pool is recycled automatically — workers may need to refresh their browser tab once.

Note: backups cover the database only. Saved poster files in workspace/ are not in the backup. They aren't affected by restore either, so as long as you don't manually delete files on disk, restoring an older DB will still find every file in its frozen folder path.
