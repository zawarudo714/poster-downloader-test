- **v288 — a SKY GRADIENT tick on REDO STEP 2.**
  **The worker folder does NOT need copying** (nothing in it changed).

  1. **The tick.** On Approve Artwork, while step 2 is on, each picture has
     a SKY GRADIENT button beside REDO STEP 2. It is off by default. Tick
     it, press REDO STEP 2, then SAVE. That picture goes back to step 2
     with the sky gradient version of the prompt.
  2. **One picture, one redo.** The tick applies only to that picture and
     only to that redo. The next REDO STEP 2 without the tick uses the
     normal prompt again. It works the same live and in a batch.
  3. **The new prompt is on the Settings page**, under Step 2, just below
     the normal step 2 prompt. It starts as the prompt you sent, with
     "gradient" instead of "solid" in the sky line.
  4. **A step 2 picture made this way says "· sky"** on its version
     button, so you can tell it apart from the others.
  5. **A blank sky prompt is refused.** SAVE says so and saves nothing. It
     never quietly uses the normal prompt instead.
